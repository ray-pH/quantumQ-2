# QuantumQ

QuantumQ is a puzzle game about quantum circuits and logic gates. This rewrite contains the 38 puzzles and four sandboxes from the original game. [Original Godot repository](https://github.com/ray-pH/quantumQ)

## Development

Setup, testing, and native build instructions are in the [development guide](DEVELOPMENT.md).

## Custom level packs

Import ZIP packs below Sandbox. Each pack can define its own sections, puzzles, and gates. Start with the [example pack](examples/starter-pack/pack.json) and see the [custom pack guide](CUSTOM_PACKS.md) for authoring and import instructions.
